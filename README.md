# Student Management System

A web-based Student Management System built using Flask, HTML, CSS, and JSON.

## Features

* Add Student
* View Students
* Search Students
* Edit Students
* Delete Students
* Dashboard Statistics

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JSON

## Installation


pip install -r requirements.txt
python student_managment.py


Open:

http://127.0.0.1:5000
